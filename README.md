Recipe App 

A simple REST API built with Node.js, Express.js, and MongoDB to manage recipes.

Features

- Create a recipe
- Get all recipes
- Update a recipe
- Delete a recipe
- Input validation using middleware

 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Render

API Endpoints

- `POST /recipes` – Create a recipe
- `GET /recipes` – Get all recipes
- `GET /recipes/:id` – Get  recipes by id
- `PATCH /recipes/:id` – Update a recipe
- `DELETE /recipes/:id` – Delete a recipe

## Run Locally

```bash
npm install
npm run dev
```

## Deployment

Deployed on Render.
